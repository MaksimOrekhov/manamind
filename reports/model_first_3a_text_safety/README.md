# MODEL-FIRST-3A-TEXT-SAFETY

**Итог:** адаптер переведён на консервативную нормализацию; экспериментальная схема признаков и cache — v2. Предыдущие `reports/model_first_3a/results.json`, checkpoint и исходная оценка сохранены без изменений. Обучения и нового split не было.

Исправления основаны на read-only чтении `claude/card-text-audit-1` (`3a4b56507b7b52de153b4d607fae5baefe979764`): старое удаление всех тегов стирало различие bold/italic, плейсхолдеры и маркеры чисел не имели пригодного контракта, а `@`-сегменты и literal-разделитель могли стать обычным текстом. Новая реализация:

- Берёт только поле `text`; `flavor`, `collectionText`, `howToEarn*` и имя карты не являются fallback.
- Удаляет только ведущий `[x]`, сводит переводы строк/NBSP/табуляцию к пробелам; сохраняет исходный регистр, цифры и пунктуацию.
- Заменяет `<b>`/`<i>` нейтральными маркерами границ форматирования. Маркеры не преобразуются в keywords или mechanics.
- Не подставляет `{0}`/`{1}` и не интерпретирует `$N`, `#N`, `(N)`, числа или `+N/+N` как значения игровых свойств.
- Маскирует весь текст карты, если встретились неразобранные `{n}`, `@`, `|`, известный literal-разделитель варианта, неизвестная/несбалансированная разметка или внутренний `[x]`. Сырые сегменты остаются только диагностикой и не попадают в TF-IDF.
- Разделяет `text_present`, `text_usable`, `text_mask` и `normalization_warnings`. Для отсутствующего текста и ID вне каталога возвращается пустой вектор с маской 0.
- Повышает `FEATURE_SCHEMA_VERSION` и cache schema с 1 до 2. Новый cache имеет новый ключ; прежний cache и результаты не перезаписываются. Скрипт повторного запуска MODEL-FIRST-3A также отказывается перезаписывать существующий results-файл.

## Read-only проверка пересечений

Добавлен `scripts/audit_model_first_3a_text_safety.py`. Он умеет показывать точные дубликаты нормализованного usable-текста, строгие functional twins (`text + type + cost + base stats + class + mechanics`), близкие текстовые шаблоны по trigram Jaccard и шаблоны после диагностической замены только цифровых последовательностей на общий маркер. Такая замена сохраняет `$`, `#`, скобки, знаки и `/`; она применяется только для поиска кандидатов, не к признакам. Проверяются также покрытие card ID/text/metadata в `state`. При передаче существующего frozen split скрипт сравнивает train/test, но **не создаёт разбиение, датасет или новые labels**.

Проверен только уже существующий ML-2A split как диагностика, не как независимая оценка: 271 ID встречается в train, 47 в test; exact text duplicates, functional twins, digit-masked templates и пары с trigram Jaccard ≥ 0,7 между ними — 0. Проверка не доказывает отсутствие семантических двойников: порог и признаки — лишь список кандидатов, а смысловые сходства могут быть невыражены буквальным текстом. В каталоге есть 7 групп точных одинаковых usable-текстов между разными ID, включая тройку `CATA_558` / `CORE_NEW1_023` / `EDR_598`.

У этих real observations уже есть история использования; registry предлагает **0** clean matches для нового split. Значит, эти счётчики — контроль протокола и инвентаризация, а не разрешение или доказательство качества для будущего Text/Hybrid обучения. До такого обучения потребуется новый заранее зафиксированный match-disjoint split и ручной анализ выдаваемых checker-ом кандидатов.
