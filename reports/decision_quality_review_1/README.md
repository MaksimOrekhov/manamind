# DECISION-QUALITY-REVIEW-1 — слепая экспертная разметка реальных ходов

Статус: **выборка и протокол зафиксированы, ждём разметку пилота пользователем.** Модели не запускались.

* Протокол и критерии: [PROTOCOL.md](PROTOCOL.md).
* Фиксация выборки (хеши, состав, без ID матчей): [lock.json](lock.json).
* Приватные файлы (позиции, manifest, метки) лежат в игнорируемом `data/processed_decision_quality_review_1/`.

## Как размечать

Из корня репозитория `E:\ManaMind`, в PowerShell.

**1. Пилот (18 экранов).** Откроется страница в браузере; метка пишется на диск при каждом «Сохранить».
Можно останавливать (Ctrl+C) и продолжать позже: сохранённое не теряется.

```powershell
.\.venv\Scripts\python.exe scripts\decision_quality_review_1.py --serve --batch pilot
```

Если браузер не открылся, перейдите на `http://127.0.0.1:8765/`. Другой порт: `--port 8770`.

**2. Заморозить пилот**, когда все 18 экранов размечены. Команда выводит проверку критериев P1–P5.

```powershell
.\.venv\Scripts\python.exe scripts\decision_quality_review_1.py --freeze --batch pilot
```

После заморозки пилота метки этого пакета больше не меняются.

**3. Main (100 экранов).** Откроется, только если пилот получил `PASS`. Лучше размечать за несколько сессий;
последние 20 экранов (повторы) — желательно в другой день.

```powershell
.\.venv\Scripts\python.exe scripts\decision_quality_review_1.py --serve --batch main
.\.venv\Scripts\python.exe scripts\decision_quality_review_1.py --freeze --batch main
```

После заморозки main сообщите об этом — сравнение моделей запускается отдельным шагом.

**Независимое ревью** спорных позиций другим человеком: тот же пакет с другим именем разметчика, метки пишутся
отдельно, например `--serve --batch pilot --rater reviewer2`.

## Что важно при разметке

* Оценивайте **следующее действие**, считая, что дальше ход будет доигран хорошо.
* Отмечайте **все** приемлемые действия; один лучший выбирать не нужно. ★ — только если уверены.
* **Грубая ошибка** — явно плохо для компетентного игрока. Без отметки — «не приемлемо, но и не грубо».
* Не хватает информации — «Недостаточно информации» и причина. Что-то показано неверно — «Проблема отображения».
* Честно отмечайте «Помню эту партию или позицию».
* Свои Секреты и Квесты видны только количеством; `[?]` — число, которое клиент подставляет в игре.
