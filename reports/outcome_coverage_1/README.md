# OUTCOME-COVERAGE-1 — покрытие Outcome Shadow

24 октября 2026. Ветка `codex/outcome-coverage-1`, основана на `main` (`6691b717f075eacde5157770c925cb8b7dd9d53f`).

## Вывод

Добавлены два общих шаблона непосредственных эффектов: `Freeze an enemy` и `Destroy a damaged enemy minion`. Они применяются по тексту, без ветвлений по ID карты. В `World` теперь переносится уже имеющийся в `GameState` флаг `hero_frozen`.

На той же выборке EVAL-2 число EXACT не выросло: **28 EXACT, 1593 PARTIAL, 100 UNSUPPORTED до и после**. При этом парсер перестал выдавать `OWN_TEXT_UNPARSED` для 55 вариантов действий из меню: 48 вариантов розыгрыша Glacial Shard и 7 вариантов уничтожения повреждённого существа. Они остались PARTIAL из-за других известных блокеров. Это измеримое увеличение известных непосредственных эффектов, но не доказательство роста силы Policy или точности на новых матчах.

## Аудит причин

Переиграны 204 решения и 1721 легальное действие из уже использованных результатов NEW-MATCHES-EVAL-2. Идентификатор набора: `9522fcec5b3768d351703517ed6f557e4c352c8e537883df6a8a91819939a906`. Это повторный анализ той же выборки, **не новый независимый holdout**. Защищённый `fresh_holdout` не открывался. Хеши действовавших источников текста: закреплённый Standard-каталог `c767c303baad170e52ee5f901ba00e8b0880eb4f0e3aa47d9fdea4fcf0bdcb34`, reviewed-тексты `476743a68c18ca2c82aa05d16f1edcd08b85d994b585bd7e701f3d0d543767e4`.

### Проверка дополнительного источника текста

Локальный `hearthstonejson_latest_enUS.json` использован только как диагностический кандидат, не как runtime-источник и не как замена закреплённого Standard-каталога. В нём 8170 записей; он содержит тексты только для 5 из 50 отсутствующих видимых ID источников действий. Добавление этого файла не меняет статусы: 28/1593/100 остаются прежними. Оно уменьшает `OWN_TEXT_MISSING` на 5, но добавляет новые неразобранные тексты (301 → 306 относительно исходного журнала) и больше выявленных реакций `BOARD_TRIGGER` (129 → 272). Поэтому подключать этот неприкреплённый широкий снимок по умолчанию не следует: он не даёт точных прогнозов и требует ручного контроля новых эффектов.

## Ограниченные исправления

1. `Freeze an enemy` теперь общий шаблон только для этой выбранной цели. Для существа записывается `frozen=True` и `can_attack=False`; для героя — `hero_frozen=True`. `hero_frozen` уже присутствовал в `PlayerObservation`, но рабочий `World` его терял. Триггеры, связанные с заморозкой, продолжают блокировать EXACT как `BOARD_TRIGGER`. Заморозка иммунного существа и далее не прогнозируется (`UNSUPPORTED`). Прогноз описывает немедленный флаг и не моделирует ход противника или истечение заморозки.
2. `Destroy a damaged enemy minion` допускается, только когда наблюдаемые `health` и `max_health` подтверждают `health < max_health`. При несоответствии цели тексту — `UNSUPPORTED`; уничтожение иммунной цели также остаётся `UNSUPPORTED`.

Для обоих шаблонов проверены синтетические точные случаи; отдельно проверены неподходящая/иммунная цель и триггер по Freeze. Тексты закреплённых `CORE_UNG_205` и `CORE_CS2_108` проверяются тестами из Standard-каталога. Ни одно правило не зависит от ID карты.

Базовый повтор до изменений совпал с сохранённым журналом по статусу каждого действия: расхождений — 0. После изменений распределение статусов осталось тем же. При стандартных источниках текста единственная изменившаяся причина неполного покрытия — `OWN_TEXT_UNPARSED`, **301 → 246 (-55)**; остальные причины из исходного журнала остались без изменения. Все эти 55 эффектов удалось вычислить, но каждое действие сохранило как минимум один независимый блокер, поэтому искусственно повышать EXACT не стали.

Новые точные шаблоны подтверждены детерминированными тестами на заданных состояниях. Игровой `EXACT` на выборке EVAL-2 не прибавился; тестовые случаи не выдаются за реальные матчи. Для 48 вариантов Glacial Shard и 7 вариантов уничтожения по-прежнему остаются другие причины PARTIAL, преимущественно отсутствующие тексты карт на столе, а для Glacial Shard также Secret противника.

## Проверки и границы вывода

- Outcome Shadow и связанные тесты (forecast, contract, context, shadow, извлечение состояния героя): 246 passed.
- Полный `pytest` в чистом снимке коммита: **1146 passed, 2 skipped**. Полный `ruff check src tests scripts` в этом снимке: **All checks passed**.
- В рабочем каталоге дополнительный полный `pytest` завершился только с ошибкой `tests/test_no_rosettastone_dependency.py`: локальный **неотслеживаемый** `vendor/RosettaStone` нарушает проверку отсутствия vendored engine. Этот посторонний артефакт не трогался. Полный рабочий Ruff также видит F401 в уже существующем неотслеживаемом `src/manamind/outcome/decision_review.py`; этот файл не менялся. Чистый прогон выше исключает оба локальных артефакта.
- В обоих полных прогонах дочерние тесты Model Shadow печатали системные Windows-сообщения `0xc0000008`/access violation в потоковом worker. Чистый pytest завершился успешно, соответствующие assertions прошли; это окруженческий stderr, а не failure этого изменения.

Сравнение ограничено тем же уже исследованным корпусом меню и проверяемой логикой правил. Оно не измеряет точность на независимом наборе матчей, не подтверждает качество Policy и не оценивает будущие реакции, случайность или выбор соперника. Не менялись LIVE Policy, Overlay, Model Shadow, рекомендации, веса Strategic Scorer, checkpoint, закреплённый каталог, ManaEngine и отчёт NEW-MATCHES-EVAL-2.

## Следующие шаги

1. Если будет отдельная задача на данные, собрать hash-pinned дополнение с reviewed-текстами отсутствующих публичных токенов/геройских способностей. Не подменять им закреплённый Standard-каталог и не брать широкий snapshot без оценки новых триггеров.
2. Добавлять грамматические шаблоны только для частых форм с полностью определяемым эффектом и тестами на несовместимые состояния. Discover, добор, история, случайный выбор, выбор противника и неописанные цепочки оставлять PARTIAL/UNSUPPORTED.
3. Для уменьшения `OPPONENT_SECRET`, `COST_UNOBSERVED`, оружейных и щитовых блокеров отдельно улучшать только легальные наблюдения/извлечение. Не ослаблять UNKNOWN по умолчанию.
