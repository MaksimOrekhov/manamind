# CARD-IR-PILOT-1 — ступень A (протокол зафиксирован)

Выборка и критерии зафиксированы в [`protocol.json`](protocol.json) **до** написания схемы Card IR и деклараций. Файл
воспроизводится скриптом [`select_sample.py`](select_sample.py) байт в байт (тест `tests/test_card_ir_pilot_1.py`).

- 16 карт из кандидатов CARD-METADATA-2 (S1–S5): в каждой страте по частоте появлений, сначала самая частая карта каждого
  типа, затем по частоте.
- 5 карт — стратифицированная случайная часть текущего Standard (+ набор BE), seed 20261026, распределение по типам
  пропорционально.
- 26 деклараций ManaEngine — первая по порядку файла в каждом семействе способностей.
- Карты не заменяются: неописуемая карта остаётся в выборке и попадает в результат как PARTIAL или UNSUPPORTED.

Игровые данные не читались; `fresh_holdout` не открывался. Отчёт с результатами появится в этом файле после
завершения пилота.
