# Сценарии CARD-IR-EXECUTION-PILOT-1

Источник истины — `scenarios.py` (ожидания написаны вручную по тексту карты и правилам Card IR до первого запуска);
таблицы ниже сгенерированы из `RESULTS.json`. Сокращения: Bolt = Lightning Bolt `CORE_EX1_238`, Flash = Flash Heal
`CORE_AT_055`, Drain = Drain Soul `CORE_ICC_055`, Overheat = `FIR_906`, Prep = Preparation (наполнитель колоды, не
разыгрывается), Senjin = Sen'jin Shieldmasta 3/5, Razorjaw = Redgill Razorjaw 3/1, Leech = Swamp Leech 2/1,
Sparks = `CORE_BOT_451` (Nature).

**Как читать.** «Ожидание» в режиме по умолчанию — это *все* изменившиеся видимые поля (рука и мана своего игрока,
здоровье героев, доска обеих сторон, Overload, размеры колод и рук); любое другое изменение — провал. «Только эти
поля» — проверяются лишь перечисленные значения после серии действий (LB-7 охватывает два хода с доборами). Доска:
`карта атака/здоровье/макс`. Каждый сценарий дополнительно проверяет, что родительская сессия не изменилась после
попытки, что у результата нет evidence debt и что `training_eligible` = false.

**Основание и свидетельство.** `TEST_CONTRACT` — ожидание следует из текста карты и правила Card IR, но не доказано
настоящей игрой. `REAL_LOG_CONSISTENT` — тот же эффект согласуется с реальными наблюдениями Power.log
(`real_evidence.json`, без holdout); это согласие величины эффекта, а не воспроизведение именно этой позиции. Статус
правила указан по словарю v0.2 (PROJECT_REVIEWED / UNVERIFIED / UNKNOWN / COMMUNITY_RULES).

**Исправленное после первого запуска ожидание:** OH-5 предсказывал код `UNSUPPORTED_CARD_IN_ACTIVE_HAND`; движок
отказывает раньше — при попадании карты в руку на стартовом доборе (`UNSUPPORTED_CARD_ENTERED_HAND`). Суть ожидания
(позиция отвергается целиком) не менялась. Проба `MUT-stats-9` добавлена после первого запуска; её прогноз вердикта
валидатора был неверен (см. README, находка 2).

## Позиции

Все позиции строятся только обычными легальными ходами прототипной сессии: колоды без перемешивания (порядок =
порядок добора), seed 0, оба места Mage (сила героя не используется). Первое
место начинает с 4 картами и 1 маной, второе — с 4 картами и The Coin.

| Позиция | Описание |
|---|---|
| `bolt_turn1` | first seat, turn 1, 1 Mana, empty boards, both heroes 30 |
| `razorjaw` | first seat turn 2 (2 Mana); enemy Razorjaw 3/1 on board |
| `senjin` | first seat turn 4 (4 Mana), own hero 26 (two Arcane Shots), enemy Sen'jin 3/5 |
| `thalnos` | first seat turn 3 (3 Mana), own Thalnos (Spell Damage +1), own hero 27 (Razorjaw hit), enemy Razorjaw 3/1 |
| `hero22` | first seat turn 3 (3 Mana), own hero 22 (four Arcane Shots), no minions |
| `cleric` | first seat turn 5 (5 Mana), own hero 22, own Cleansing Cleric played (healing bonus 2) |
| `drain_no_minion` | first seat turn 2 (2 Mana), no minions anywhere |
| `overheat` | first seat turn 3 (3 Mana), own Swamp Leech 2/1 and Razorjaw 3/1, no Nature spell in hand |
| `overheat_nature` | as overheat, plus Lightning Bolt (Nature) in hand |
| `overheat_two_nature` | as overheat, plus Lightning Bolt and Sparks (both Nature) in hand |
| `overheat_empty_board` | first seat turn 3 (3 Mana), no minions, Lightning Bolt in hand |
| `unsupported_in_hand` | first seat turn 1 holding Innervate, a Nature spell ManaEngine does not support |
