## Гипотезы и заранее выбранный протокол

- **Базовая модель:** неизменённый production Policy v2, SHA-256 `044b9b50cd6b33912faf8dabe42d919305cb238a8d5cbfb1edf30bb3689d1e4d`.
- **Больше данных:** та же PolicyNetworkV2, обученная с нуля на train-части 37 старых пригодных матчей, должна улучшить совпадение с действиями игрока относительно frozen v2.
- **Текст:** небольшой дополнительный канал TF-IDF для видимой карты-источника действия должен улучшить результат относительно Retrained v2 без ухудшения отдельных типов действий.
- Один seed `42`, CPU/один поток, AdamW, learning rate `0.001`, weight decay `0.001`, batch `32`, градиент `1.0`, dropout `0.1`, максимум `30` эпох и patience `6`. Выбор эпохи только по наименьшей validation cross-entropy с `min_delta=0.0001`. Эти параметры зафиксированы в [конфигурации](../../configs/ml_pilot_1.json) до обучения; подбор после просмотра development test не проводился.

Тест состоит из 16 матчей 10 октября. Пользователь видел рекомендации v2 во время игры, а DATA-CHECKPOINT-1 уже исследовал эту группу. Поэтому это **DEVELOPMENT TEST**, не независимый holdout. Здесь сравнивается только имитация действий игрока; игровая полезность отдельно не проверялась.

## Модели и корректность

Retrained v2 использует прежний `PolicyNetworkV2` и прежний encoder без изменения входных колонок; checkpoint выбран на эпохе **12**. Hybrid использует ту же основу плюс отдельный `HybridPolicyV2`: TF-IDF вектор из существующего `CardTextAdapter` проходит через маленький слой 4664→32→1 и добавляется к logit каждого легального действия. Основа не получает новых входных колонок. Checkpoint выбран на эпохе **3** при том же бюджете и правиле остановки. Разная выбранная эпоха — результат одного заранее принятого validation-правила.

Текст берётся только из закреплённого Standard-каталога. Канал получает карту-источник текущего действия из SELF hand или публичной сущности; скрытые карты противника не передаются. `text_usable=false`, неизвестный ID, неизвестный placeholder и END_TURN дают нулевой текстовый вектор и маску 0. Текстовый канал не получает embedding ID карты и не подставляет эффект для отсутствующего текста. Отдельный экспериментальный checkpoint хранит полный контракт v2, каталог/словарь, конфигурацию текста, упорядоченные terms и разреженную таблицу TF-IDF; загрузчик проверяет их против закреплённого каталога. На validation-пробе удаление текста изменило logit максимум на **0,34**, то есть канал действительно влияет на выход. Тест маски проверил нулевой вклад при `usable=0`.

Для выбранной карты-источника, встречавшейся среди видимых train-наблюдений, Top-1: **38,90 / 39,14 / 36,04%** (419 решений); для не встречавшейся: **37,76 / 38,78 / 32,65%** (98 решений).
