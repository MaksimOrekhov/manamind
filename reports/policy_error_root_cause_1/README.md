# POLICY-ERROR-ROOT-CAUSE-1

Статус: **COMPLETE — read-only diagnosis**. База: `3e03ca0f919c63892c4c18208e967d2a9c920ecd`, ветка `codex/policy-error-root-cause-1`. Обучения, изменения Policy, Scorer, guard, каталога и LIVE нет.

**У 4 из 12 исходных BLUNDER есть сильное локальное объяснение ошибки выбора.** Ещё у двух есть вероятное объяснение; для шести исходная оценка не получает достаточно независимого технического обоснования. Это объяснение поведения на конкретных позициях, а не доказательство причин в весах сети. Четыре случая Catacombs нельзя считать четырьмя подтверждёнными ошибками порядка.

Следующий рекомендуемый эксперимент — **A: небольшой пилот с данными нужных колод при неизменных входах и архитектуре v2**. Сначала нужно подготовить и проверить новый независимый набор и разделение по матчам. Здесь пилот только описан, не запущен.

## Что проверено

- Заново импортированы только 19 разрешённых матчей; их SHA проверены по исходному lock. До открытия игровых файлов проверено отсутствие пересечения с девятью `fresh_holdout`, включая 16-символьные префиксы имён raw-файлов. Содержимое `fresh_holdout` не читалось.
- Все 48 состояний и полных меню совпали с frozen pool. Все полные рейтинги Frozen v2 и Scorer v3 совпали с frozen comparison. Исходные метки, manifests, pool и checkpoint проверены на неизменность до и после диагностики.
- Для всех 48 приватно сохранены before-state, полное меню, исходные метки, выбор игрока, все logits/softmax Policy, scores и breakdown Scorer, прогнозы с unknowns, метаданные и сведения о входах. Top-5 каждого метода — первые пять индексов соответствующего полного рейтинга; при меню меньше пяти сохранено всё меню. Softmax — доля внутри меню, **не вероятность правильности или победы**.
- Проверен точный обучающий snapshot checkpoint: 21 матч / 736 решений и его dataset hash; анализ экспозиции использует только train **17 матчей / 591 решение**. Ни один новый матч аудита не используется для обучения.
- Количественный контроль — **все остальные 36 позиций**, а не удобная подвыборка. Это 30 ACCEPTABLE и 6 позиций без Top1 BLUNDER, но также без Top1 ACCEPTABLE. Иллюстрации выбираются по первому frozen ordinal, удовлетворяющему опубликованному условию.

## Ограничения интерпретации

Сохраняются исходные 62,5% ACCEPTABLE и 25% BLUNDER Policy, 70,8% и 25% Scorer. `CLEAR_MISTAKE` — отдельная диагностическая отметка внутри исходных 12; остальные метки не исправлялись. Четыре случая не образуют новую оценку частоты ошибок на всех 48.

Один исходный оценщик также является игроком. Стабильность основной разметки не измерена; три повторных экрана pilot этого не исправляют. В среднем допустима примерно половина меню; END_TURN отмечен BLUNDER в 46/48. Поэтому большой Top3 и согласие с игроком сами по себе не подтверждают стратегическую силу. Две SELF-классовые группы и связанные позиции внутри матчей ограничивают перенос вывода. Никакой из этих результатов не устанавливает выигрыш по winrate.
